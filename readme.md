# About
A simple tool to improve Tkinter/CustomTkinter UI development by giving a visual of any window size and window position. All you have to do is size the window in anyway you would like. 
The console also outputs two size strings based on window size and position:
* Regular size string: ```WidthxHeight```
* Size string: ```WidthxHeight+X+Y```
# How to run
To run, have any version of python installed with Tkinter module built in, then run main.py file from any console with python to start.
